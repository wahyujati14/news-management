Cara
Saya membuat ini dengan Laravel 10, dengan PHP versi 8.1.0
1. git clone https://github.com/wahyujati14/news-management.git
2. composer require laravel/passport
3. composer install
4. php artisan migrate
5. php artisan db:seed
6. php artisan serve

*Keterangan :
1. Saya hanya bisa sampai di pembuatan laravel passport untuk autentikasi Oauth 2.0
